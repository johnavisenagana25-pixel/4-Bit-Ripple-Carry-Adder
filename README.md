# 🔷 4-Bit Ripple Carry Adder using Verilog HDL

## 🎯 Objective

To design and simulate a 4-Bit Ripple Carry Adder using Verilog HDL for performing binary addition and verifying sum and carry outputs through simulation.

## 📝 Description

This project implements a 4-Bit Ripple Carry Adder using multiple full adders connected in series. The carry generated from one stage propagates to the next stage. Simulation and waveform analysis were performed using EDA Playground.

## ✨ Features

* 4-Bit Binary Addition
* Carry Propagation
* Sum and Carry Output Generation
* Full Adder Based Design
* Waveform Verification

## 🛠 Tools Used

* Verilog HDL
* EDA Playground
* Icarus Verilog
* EPWave

## 📂 Files Included

* ripple_adder.v
* testbench.v
* README.md
* waveform.png
* output.png

## 📊 Output

The simulation output verified correct binary addition functionality for different input combinations. Waveforms showed proper carry propagation and accurate sum generation.
